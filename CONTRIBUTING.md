# Contributing

1. Pull the latest `develop`.
2. Create `feature/<short-name>`.
3. Do not change the frozen `/api/v1` contract without project-lead approval.
4. Add/update tests.
5. Open PR to `develop`; include APIs touched, migrations/config, and test steps.
6. Never commit `.env`, credentials, real patient data, build output, IDE caches or database dumps.
